### 🎨 Backend ที่อยากให้ UI สวยด้วย

| 🧠 Engineer mindset | 🎨 Designer mindset |
| :--- | :--- |
| API ต้องเร็ว ต้องเสถียร | Interface ต้องใช้ง่าย ไม่ต้องคิดเยอะ |
| Error handling ต้องรัดกุม | Error message ต้องเป็นมิตรกับคน |
| Clean architecture | Clean layout & spacing |
| Latency ต่ำ | Perceived performance ดี |

> _"Good software works well. Great software feels good too."_
